# POLYGON
<h2> About THE Project:</h1>
<h3>I made a simple 3-d website of Cristiano Ronaldo by using HTML5, CSS3, JAVA SCRIPT, and the important things THREE JS. I added 4 objects like(2 cube, 1 rings and stars). I added about him, his stats, his achievements in the page and style that with using CSS3. I fell really amaze while making this project and learn about THREE JS while making this project </h3>

<h2>Feature:</h2>
<ul>
  <li>Animated 3D star field with twinkling and color variation</li>
  <li>Scroll-based camera movement</li>
  <li>Advanced lighting system (ambient, directional, hemisphere, point lights)</li>
  <li>Rotating torus rings around 3D objects</li>
  <li>1000+ floating animated particles</li>
  <li>Responsive design </li>
  <li>CR7 stats, achievements and biography sections</li>
</ul>
